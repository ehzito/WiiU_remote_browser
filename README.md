# WiiU_remote_browser
Remote browser server for Nintendo Wii U. Renders modern sites via macOS Chromium &amp; streams JPEG screenshots to the console's browser.  Experimental project with legacy HTML, HTTPS/TLS 1.2 &amp; local auth. Not affiliated with Nintendo.  Note: Might work on other older browsers too, but main focus was 100% Wii U! Feel free to test :D
